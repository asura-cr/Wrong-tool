# [RPG IN EXCEL]
> This is a rpg game made in excel using vba

## **DEMO**
> - To play download the the latest [release](https://github.com/asura-cr/Wrong-tool/releases/latest) and open the .xlsm , go to developer tab click on macro security

> [!NOTE]
> if you still get an error saying cannot run the macro go to [Solve excel vba macro error](#SOLVE-ERROR)

### START GAME
> - Click on the start button and wait a bit
> - Use WASD Or Arrow keys , and 1/2 to use attacks or defend
> - Defending reduces damage recieved by half , killing a mob gives a random chance to drop a random loot

> - right click on the downloaded file and go to properties
> - click on unblock at the end of the window and click on ok/apply
